# 原生内容站技术详设

## 1. 需求概述

广告主创建博文任务，通过**上传 mids** 或按**品牌词/话题词圈选**收集博文；对博文做分层等级、热度指数、传播指数、gid 四维计算；筛选优质博文（收藏/分层统计）打包后供**聚宝盆**拉取投放。设计量级：单任务 10 万条 mid。（详见产品文档：[《原生内容站（自然博文捞取）》](https://alidocs.dingtalk.com/i/nodes/3NwLYZXWyzyP9YrPSNEDybP7VkyEqBQm)）

## 3. 存储设计

| 表 | 说明 |
| --- | --- |
| 广告主配置表<br>`nature_ad_customer_config`【新】 | 广告主配置，一 customer 一行。<br>存行业、品牌词。<br>brand\_tag 存 json `{"tagid":"品牌词"}`（key=标签库 tagid=圈选 third\_tagids，value=展示文案）；industry\_tag 逗号串；is\_del 软删 |
| 任务表<br>`super_mid_task`【改】 | 任务表。<br>新增 6 列：start\_time、end\_time、brand\_tag(json)、topic\_code(逗号串)、exec\_status(0待执行/5停止)、task\_type(0-Basestar/1-bp) |
| 博文表<br>`nature_ad_super_mid_0..19`【新】 | 优质博文 20 分表（分片键 `customer_id % 20`）；<br>存上传博文+圈选博文明细 |
| `super_mid`（旧） | 历史表，保留原名，回刷后停读停写 |
| 博文包<br>`super_mid_package`【新】 | 博文包，mids 存 short\_url 逗号拼接（单包 ≤200） |

**路由规则**：带 customer\_id → 单表路由；不带 → 全路由 20 表归并（热度 Job、传播拉取/回写）。

**详细表结构：**[《原生内容站涉及表结构》](https://alidocs.dingtalk.com/i/nodes/b9Y4gmKWrdnz6Zezuelpw5YaJGXn6lpz)

## 4. 接口公共约定

*   **统一返回**：code≠0 即失败。
    
*   **公共参数**（上游网关注入 query）：`customer_id`（广告主uid，bp 侧接口必填）、`operator_uid`/`operator_name`（Basestar配置管理侧必填）。
    
*   时间格式统一 `yyyy-MM-dd HH:mm:ss`。

## 6. 模块二：任务管理（task\_type=1 固定）

### 6.1 创建任务

`POST /api/v1/supermidbp/save?customer_id={uid}`

**入参（JSON Body）**：

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| name | string | 是 | 任务名称 |
| mids | string | 三选一\* | mid 或博文链接，逗号分割，≤200 条 |
| startTime | string | 是 | 任务开始时间<br>此时此刻以后 |
| endTime | string | 是 | 任务结束时间，必须大于 startTime<br>仅可startTime ~ 15天内 |
| brandTag | string | 三选一\* | 品牌词 tagid，逗号分割，≤10 个；<br>必须存在于该 customer 品牌词配置 json key 中；<br>不能与其他有效任务重复 |
| topicCode | string | 三选一\* | 话题词，逗号分割，≤10 个；<br>不能与其他有效任务重复 |

*   mids/brandTag/topicCode 至少传一个。词排他：一个词仅能被一个有效任务（exec\_status≠5）使用。
    
    **逻辑**：
    
    1.  博文上传单次最大支持200个（继续支持mid/url形式）；
        
        1.  针对转发博文：要记录表forward\_mid、forward\_uid、forward\_mid\_text数据
            
    2.  博文写 `nature_ad_super_mid_{customer_id%20}`；任务按 task\_type=1 落库；
        
    3.  有上传的mid发 kafka 触发 gid 计算；
        
    4.  成功后刷新圈选 Redis 缓存，缓存key: ad\_bp\_orders。（注意：与内容小喇叭共用圈选博文缓存配置，根据order\_type区分：1-原生内容站任务、99-内容小喇叭任务）
        
    
    **返回值**：`payload = {successCount, failedMids:[{mid, reason}]}`
    
    ```bash
    curl --location --request POST '127.0.0.1:8058/api/v1/supermidbp/save?operator_name=ai&operator_uid=2608812381&customer_id=2608812381' \
    --header 'Content-Type: application/json' \
    --data-raw '{
        "name": "我的博文包-7",
        "startTime": "2026-08-01 12:00:02",
        "endTime": "2026-08-27 12:00:02",
        "brandTag": "tag-2",
        "topicCode": "话题词1,话题词2",
        "mids": "https://weibo.com/3038801145/RdYbFyaOC?pagetype=groupfeed,https://weibo.com/2050767771/QgwoSCDl4,https://weibo.com/7166745594/Qgw0zjnyZ?refer_flag=1001030103_,https://weibo.com/7008866503/5239345868702306,5239345868702306,https://weibo.com/3276492000/Qug9o8CQp?pagetype=profilefeed,5323807284005498,5323773890529952,5323603396788311"
    }'
    
    
    {
        "payload": {
            "successCount": 6,
            "failedMids": [
                {
                    "mid": 5272119262055945,
                    "reason": "暂不支持明星类博主的博文打分预估"

    ```
    
    ### 6.2 编辑任务
    
    `POST /api/v1/supermidbp/task/edit?customer_id={uid}`
    
    **入参（JSON Body）**：taskId（必填）；mids / endTime / brandTag / topicCode 至少其一（均选填）
    
    **逻辑**：
    
    1.  任务不存在/非本人/已停止（exec\_status=5）均报错；
        
    2.  endTime 只能延长（≥库中值）仅可startTime ~ 15天内；
        
    3.  brandTag/topicCode 只能追加（与本任务已有重复报错，合并后各 ≤10，与其他有效任务排他校验：即不能与其他有效任务重复）；
        
    4.  追加 mids 与该任务已有 mid 重复报错，走同一分批入库流程，mid\_total 累加；（转发博文处理同创建任务）
        
    5.  成功后刷新圈选 Redis 缓存。
        
    
    **返回值**：同 6.1（successCount 为本次追加 mids 成功数）。
    
    ```bash
    curl --location --request POST '127.0.0.1:8058/api/v1/supermidbp/task/edit?operator_name=ai&operator_uid=2608812381&customer_id=2608812381' \
    --header 'Content-Type: application/json' \
    --data-raw '{
        "taskId": 1296787623758528513,
        "endTime": "2026-08-29 12:00:02",
        "brandTag": "tag-3",
        "topicCode": "话题词3",
        "mids": "4876329553760906"
    }'
    
    
    {
        "payload": {
            "successCount": 1,
            "failedMids": []
        },
        "header": {
            "code": 200,
            "message": "Success"
        }
    }
    ```
    
    ### 6.3 停止任务
    
    `POST /api/v1/supermidbp/task/stop?customer_id={uid}&super_task_id={taskId}`
    
    **逻辑**：
    
    1.  exec\_status 置 5；
        
    2.  仅能停止自己的任务；
        
    3.  立即刷新圈选 Redis 缓存剔除；
        
    4.  停止后其品牌词/话题词释放，可被其他任务复用
        
    
    ```bash
    curl --location --request POST '127.0.0.1:8058/api/v1/supermidbp/task/stop?operator_name=ai&operator_uid=2608812381&super_task_id=1296787623758528513&customer_id=2608812381'
    
    
    {
        "payload": "",
        "header": {
            "code": 200,
            "message": "Success"
        }
    }
    ```
